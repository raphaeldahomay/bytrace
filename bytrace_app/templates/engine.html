How the Engine Works

1. User input

The user writes a value in the input field and chooses the type of conversion they want to perform.

2. Flask receives the data

When the form is submitted, Flask receives the input through a route. This route acts like a door between the web page and the Python backend.

3. Python converts the value

The backend checks which converter was selected, then applies the correct Python logic. For example, text can be transformed into binary, or binary can be transformed back into text.

4. The result is sent back

Once the conversion is done, Flask sends the result back to the HTML page, where it is displayed to the user.

Input → Flask Route → Python Logic → Output
